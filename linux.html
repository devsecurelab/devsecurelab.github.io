Learning Modules

Complete each lesson and knowledge check in order.

Module 01:

Filesystem Structure & Navigation

30 minutes

Objective: Understand the Linux root hierarchy and move safely through absolute and relative paths.

Practice: Use a practice directory and list files sorted by modification time.

pwd
ls -la /var/log
Which command prints the current working directory?

Module 02:

File Creation & Text Viewing

35 minutes

Objective: Create, copy, inspect and append to text files without modifying system files.

Practice: Create a dummy audit file and append one timestamped line.

touch audit.txt
head -n 20 audit.txt
tail -n 20 audit.txt
Which command displays the last lines of a file?

Module 03:

Permissions & Ownership

40 minutes

Objective: Interpret rwx permissions and apply safe numeric modes to practice files.

Practice: Set owner read/write, group read, and no permissions for others on a dummy file.

chmod 640 audit.txt
ls -l audit.txt
Which octal mode gives owner read/write and group read only?

Module 04:

Users, Groups & Processes

45 minutes

Objective: Inspect users, groups, processes and service status without changing system state.

Practice: Find the PID of your current shell using a read-only command.

id
ps aux | head
systemctl --no-pager status ssh
Which command lists running processes?

Module 05:

Logs, Grep & Pipes

50 minutes

Objective: Filter sample logs to find errors, failed logins and operational patterns.

Practice: Create a sample log and count repeated error messages.

grep "ERROR" sample.log | sort | uniq -c
Which operator sends one command output to another command input?

Module 06:

Linux Networking Commands

55 minutes

Objective: Inspect local interfaces, routes, sockets and loopback connectivity.

Practice: Run local diagnostics and record the output in your lab notes.

ip addr
ip route
ss -tuln
ping -c 2 127.0.0.1
Which command lists listening sockets?

Module 07:

Bash Shell Automation

60 minutes

Objective: Write safe scripts with variables, conditions, exit codes and quoted paths.

Practice: Create a script that reports disk usage without changing files.

#!/usr/bin/env bash
set -euo pipefail
printf "Audit started\n"
Which line selects the Bash interpreter?

Module 08:

System Audit & Hardening Project

65 minutes

Objective: Apply least privilege and document a read-only local system audit.

Practice: Audit only a disposable `./lab` directory and write remediation recommendations.

find ./lab -type f -perm -002 -print
find ./lab -type f -name "*.sh" -print
Why are risky SUID or writable permissions important to review?
