# DevSecureLab Level 5 Audio

Every lesson includes a `Listen to this lesson` control powered by the browser Web Speech API. This keeps the static GitHub Pages package lightweight and avoids external audio hosting or tracking. The lesson audio uses the learner's browser voice, can be paused/resumed, and respects the global Audio On/Off setting.

Quiz feedback sounds use the Web Audio API. Optional vibration is used only on supported mobile devices and never replaces written feedback. Learners can disable audio, and reduced-motion preferences suppress vibration.
