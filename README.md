# DevSecure Lab Level 10

A static, English-first cybersecurity learning platform with six tracks, 48 structured modules, safe exercises, guided projects, audio narration, quizzes, progress tracking and accessibility support. Bengali support appears only inside the English for Cybersecurity learning track.

## Upload
Upload the contents of this folder to the GitHub Pages repository root. Do not upload the ZIP or checksum file.

## Safety
The platform is educational. Use labs only on owned, disposable or explicitly authorized systems. The Python playground is a controlled browser simulation and does not execute arbitrary code.
