# DevSecureLab Level 5

DevSecureLab is a free, self-paced cybersecurity learning platform for global students.

## Learning paths

Linux → Networking → Python → Web Security → Ethical Hacking

A dedicated **English for Cybersecurity** track adds practical communication skills from vocabulary to professional presentations. Bengali support text appears only inside that English-learning track; all other website UI and learning content remains English-only.

## Level 5 features

- Six tracks with 48 structured modules.
- Lesson audio on every module through browser speech synthesis.
- Audio On/Off control, pause/resume, written quiz feedback, optional feedback sounds and supported-device vibration.
- Reduced-motion support and accessible keyboard controls.
- Open Graph and X/Twitter social metadata with a branded 1200×630 preview image.
- Page-specific canonical URLs, robots.txt and sitemap.xml.
- Networking, web security and Python explanatory visuals.
- Privacy Policy and Responsible Use Policy.
- Local browser progress storage; no accounts or cloud synchronization.

## Local preview

Open `index.html` in a modern browser, or serve the folder with a static web server. Browser audio requires a browser with speech synthesis support. Some browsers may restrict speech or sound until the user interacts with the page; use the visible lesson audio button after interaction.

## GitHub Pages upload

Upload the contents of this folder to the repository root. Keep `assets/` and `.github/` in their original locations, replace the previous files, commit to the main branch and wait for GitHub Pages deployment.

All cybersecurity activities are for owned, local, disposable or explicitly authorized environments only.
