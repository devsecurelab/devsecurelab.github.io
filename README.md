# DevSecureLab Level 4

DevSecureLab is a free, self-paced, English-only cybersecurity learning platform for global learners.

## Learning path

Linux → Networking → Python → Web Security → Ethical Hacking

## Local preview

Open `index.html` in a modern browser, or serve the folder with any static web server. Progress is stored locally in the browser through `localStorage`; this package does not include accounts or cloud synchronization.

## GitHub Pages upload

Upload the contents of this folder to the repository root. Keep the `assets/` and `.github/` directories in their original locations. GitHub Pages should publish from the repository’s main branch and root folder.

## Included features

- Five courses with 40 structured modules.
- Accessible keyboard navigation, skip link, visible focus states and reduced-motion support.
- Interactive knowledge checks and local progress tracking.
- Dark/light theme persistence.
- Privacy Policy and Responsible Use Policy.
- 404 page, robots.txt, sitemap.xml and GitHub Actions validation.

All security exercises are for owned, local, disposable or explicitly authorized environments only.
